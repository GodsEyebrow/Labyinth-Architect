Labyrinth Architect
Build huge, multi-floor underground labyrinths from your own schematics – configured entirely in-game.

Labyrinth Architect turns a handful of building blocks – a tower, a few corridor pieces, stairs and rooms – into a complete maze of up to 1023 × 1023 chunks spread over several floors. You design the pieces, the mod generates the maze, stitches everything together block-perfectly and places it into your world without lag.

Requires only Fabric API. No Litematica, no WorldEdit, no other dependencies.

✨ Highlights
🧱 Your schematics, your style – use .nbt (structure blocks), .schem (WorldEdit / Sponge v2 & v3) or .litematic (Litematica, including multi-region files). Neither Litematica nor WorldEdit needs to be installed.
🗺️ Massive multi-floor mazes – default 81 × 81 cells on 5 floors, up to 1023 × 1023, or an endless labyrinth that grows with your world.
⚡ No lag – blocks are placed in small, tick-budgeted steps that adapt to server load. TPS stays at 20, even while a full 81 × 81 × 5 labyrinth (60 million blocks) is being built.
🖥️ Complete in-game editor – seven tabs, live map preview, schematic picker with a textured 3D preview.
⛏️ Tunnel carving tool – draw tunnel cross-sections and carve them through any building block, right in a 3D view.
🎁 Loot – chests in dead ends, rooms and stairs, getting better the deeper (or further out) you go.
🔁 Deterministic – same seed + same preset = the exact same labyrinth, every time.
🏗️ How it works
The labyrinth is a grid of cells – one cell is one chunk (16 × 16 blocks). Every floor is filled with a maze generated by a growing-tree algorithm, then built from your schematics:

Element	What it does
Tower	Stands in the centre, connects all floors, four entrances per floor
Corridors	Dead end, straight, corner, T-junction and crossing – rotated automatically, several weighted variants per shape
Stairs	Connect one floor with the next
Rooms	Span several cells and even several floors, with freely placed openings
You control branching, the number of loops, stairs per floor, outer exits, spacing between rooms and much more. Floors may have different heights, and the whole volume around the elements is filled with a block of your choice (stone by default – the labyrinth lives underground).

Schematics smaller than 16 × 16 are fine: the mod centres them in their cell and fills the rest. Openings, floor offsets and the element type are detected automatically, and every schematic gets a clear status ✔ / ⚠ / ✘ with the reason and a suggested fix.

🌍 Two ways to place a labyrinth
Into an existing world
/labyrinth generate → /labyrinth confirm. The mod builds chunk by chunk with an adaptive time budget per tick and shows a progress bar. Pause, resume or cancel at any time – the job even survives a server restart and continues where it stopped. Lighting is recalculated correctly.

During world generation
Enable the labyrinth for a world and it appears as new chunks are generated – either as one labyrinth at a chosen position or as an endless labyrinth made of connected regions that never ends.

🖥️ The in-game editor
Press U (or /labyrinth gui) to open the editor:

General – presets (save, load, import, export as JSON), seed, size, floors, base height, fill block, algorithm settings, placement mode
Tower / Corridors / Stairs / Rooms – choose schematics and fine-tune every element
Loot – rules for chests
Preview – a map of every floor with zoom and pan, exportable as PNG
📂 Schematic picker with 3D preview
Browse folders, search, filter by type, and inspect every schematic in a fully textured 3D view – rotate with the left mouse button, zoom with the wheel, pan with the right mouse button.

📥 Importing schematics
Click "Import schematic" – a native file dialog opens right in your Downloads folder and shows only .litematic and .schem files. Or simply drag & drop files onto the window. The file is checked, copied into the library and selected immediately.

⛏️ Tunnel profiles & carving
Want an arched passage through a room, a round tunnel through the tower or a horseshoe-shaped gallery?

Draw a profile – a grid editor up to 32 × 32 with templates for rectangle, arch, circle and horseshoe. Save your profiles and reuse them.
Place it in 3D – click a block face in the 3D view, or move the tunnel with the arrow keys. Choose axis, rotation and length. Blocks that will be removed are highlighted in red.
See the result – the preview shows the carved element live.
Apply – the carve is stored with the element and used automatically whenever the labyrinth is built. Your schematic files are never modified.
🎁 Loot
Automatic chests in dead ends, corridors, rooms and stairs, with configurable chances
Better loot on deeper floors and/or further from the centre (tiered loot tables)
Loot markers inside your schematics become chests
Ships with its own loot tables – replace them with a data pack if you like
🛡️ Robust by design
Broken, oversized or manipulated schematic files can't crash the game – sizes are checked before anything is loaded, and decompression bombs are rejected.
Old schematics are upgraded to the current Minecraft version automatically.
Every problem is shown as a clear, translated message with a hint on how to fix it.
Designed for singleplayer and multiplayer servers: the server makes every decision; the editor requires operator permission (level 2).
Fully translated: English and German.
⌨️ Commands
All commands require operator permission.

Command	Description
/labyrinth gui	Open the editor
/labyrinth generate [center] [seed] [size]	Prepare a labyrinth with the starter set
/labyrinth generate preset <name> [center]	Prepare a labyrinth from a saved preset
/labyrinth confirm	Start the prepared labyrinth
/labyrinth pause · resume · cancel · status	Control the running job
/labyrinth worldgen fixed <preset> [center]	Generate one labyrinth during world generation
/labyrinth worldgen endless <preset> [regionSize] [openings]	Endless labyrinth during world generation
/labyrinth worldgen status · disable	Show or disable world generation
/labyrinth schematics · schematic <path>	List schematics / show details
/labyrinth reload · validate · presets	Reload, check and list
/labyrinth preview <floor>	Save a floor map as PNG
/labyrinth debug cell	Show the cell under your feet
🚀 Getting started
Install Fabric Loader and Fabric API for Minecraft 26.3.
Put Labyrinth Architect into your mods folder.
Start the game – a starter set of schematics and a ready-to-use preset are created in config/labyrinth_architect/.
Create a world with cheats enabled, stand where you want the labyrinth and run /labyrinth generate, then /labyrinth confirm.
Open the editor with U and start replacing the starter pieces with your own builds.
⚠️ Placing a labyrinth into an existing world overwrites all blocks in its volume. Make a backup first.

❓ FAQ
Do I need Litematica or WorldEdit? No. Their file formats are read directly by the mod.

Does it work on servers? It is built server-authoritative: the server generates and places everything, and players with operator permission use the editor. Importing files from your own computer is only available in singleplayer or as LAN host – on a dedicated server, the admin copies schematics into the server's config/labyrinth_architect/schematics/ folder.

Does it work in superflat worlds? Placement into an existing world works everywhere. The world-generation mode needs a world type that runs world generation features (normal worlds do; superflat only if its preset enables features).

Can I use modded blocks? Yes, as long as the mod that adds them is installed. Unknown blocks are replaced by air with a warning.
